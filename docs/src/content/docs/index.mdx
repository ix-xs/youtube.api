<section class="at-section">
  <header data-reveal><span>02</span><h2>What you stop writing</h2></header>
  <ul class="at-points">
    <li data-reveal><h3>Page token loops</h3><p>Every list can be awaited for one page or walked with <code>for await</code>. Pages are fetched as you go, at the size that costs the least.</p></li>
    <li data-reveal><h3>Chunks of 50 ids</h3><p>Pass 500 video ids. They are split into calls, sent together and merged back, in the order you gave.</p></li>
    <li data-reveal><h3>Handle and URL parsing</h3><p>A channel is <code>@handle</code>, any URL or an id. Same for videos and playlists. Ids resolve for free, handles are remembered.</p></li>
    <li data-reveal><h3>Quota arithmetic</h3><p><code>yt.quota</code> counts what you spend per bucket and per method, knows when it resets, and can refuse a call before it leaves.</p></li>
    <li data-reveal><h3>The OAuth dance</h3><p>Consent URL with PKCE, code exchange, refresh before expiry and after a 401. For a script, one call opens the browser and stores the tokens.</p></li>
    <li data-reveal><h3>The upload protocol</h3><p>Give a file. Small ones go in one request, large ones in resumable chunks with progress, retries and resume.</p></li>
  </ul>
</section>
